How the update works

  1. Stage update.uf2 on the SD card root.
  2. Boot the PicoPad with the card inserted. The launcher sees the file, verifies it, flashes it and deletes it.
  3. If the version on the card is newer, it offers the update; equal or older versions are ignored.

A previous update.uf2 is copied to update.uf2.bak before staging.

Connection

Run LINK START on the ESP32 once (or add it to the sketch). Default port 2323.

Start here

  1. Plug the SD card into this computer and pick it above.
  2. Use SD card to install games, payloads and themes.
  3. Use Updates to stage a launcher build.
  4. Use Device to control the PicoPad over USB or WiFi.

On a phone

Run this app on a computer on the same network, then open the Network URL shown in the terminal. Add it to the home screen and it behaves like an app.

USB control

Open TOOLS → Companion Link on the PicoPad, then connect here.

Needs the optional serialport package: npm install in companion/.

WiFi control

Flash the bridge in esp32/wifi_bridge, connect the ESP32 to the PicoPad UART, then send LINK START once. Point the app at the ESP32 IP (or picopad.local) and port 2323.

Command reference

PING                 → PONG
INFO                 → INFO <version> <board> <heap>
STATUS               → STATUS <ver> <mv> <pct> <sd> <usb> <esp> <theme>
APPS                 → APPS <n> + APP <id> <label> … + END
LAUNCH <id>          → launch a game, tool or fun app
THEMES               → THEMES <n> + THEME <name> … + END
THEME SET <name>     → activate a theme
SAVER                → show the screensaver
REBOOT               → reboot the launcher
BOOTSEL              → reboot into the RP2040 bootloader
